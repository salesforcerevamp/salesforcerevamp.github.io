Release Changelog

Track all improvements, enhancements & fixes across versions

v1.4.2

Released : 3rd April 2026
  • New UI Across the Board [Updated] — Introduced a completely redesigned interface across the extension. The new UI provides a cleaner layout, better visual consistency, and improved usability for everyday Salesforce navigation.
  • Complete Redesign from Scratch [Major] — Rebuilt major parts of the extension architecture from the ground up. This redesign improves maintainability, stability, and prepares the foundation for future advanced features.
  • Global Header Controls [New] — Introduced a new customization control that lets users hide or show icons and buttons in the top-right section of the Salesforce global header. This helps create a cleaner workspace by displaying only the actions you use most.
  • Flow Metadata Downloader [New] — Added a new tool to download Flow metadata directly from the Flow Builder page. Developers and admins can now quickly extract Flow definitions for inspection, documentation, or debugging.
  • Direct Go To Field Setup [New] — Added a quick shortcut to jump directly to the Field Setup page from record fields. This removes multiple navigation steps and makes field configuration changes much faster.
  • One-Click Debug Logs [New] — Added a quick option in the Login As tab to generate debug logs for users with a single click. This eliminates the need to manually navigate to Setup and configure trace flags, making troubleshooting and debugging significantly faster for admins and developers.
  • Expand / Collapse Sections [Improved] — Replaced the large text button with a compact icon button for expanding or collapsing sections. The control is now streamlined for a cleaner interface and is restricted to appear only on record pages to avoid clutter across other Salesforce screens.
  • Faster and Smoother UX [Improved] — Performance optimizations across the extension improve responsiveness and reduce delays. Element detection and script execution are now significantly faster, especially in large Salesforce orgs.
  • Minor Bugs Fixed — General performance and stability improvements across extension pages.

v1.4.1

Released : 6th March 2026
  • Password Reveal [New] — Added a quick eye toggle on the login page to show or hide passwords instantly. No more typing mistakes while logging in.
  • Header List Scroll [New] — New option to hide or display scrollbars in global header dropdown lists, giving Salesforce a cleaner and distraction-free look.
  • Expand / Collapse Sections [New] — Added a one-click toggle on record pages to expand or collapse all sections instantly. Perfect for navigating large layouts faster.
  • Required Field Highlighter [New] — Required fields are now boldly highlighted, making it much easier to identify mandatory inputs while filling forms.
  • Auto Fill Fields (Tester Mode) [New] — Added a smart Auto-Fill button in Create/Edit Quick Actions to quickly populate fields for testing and demos. Note: Currently supports standard input fields only. Lookup, Picklist, Multi-Picklist, and Address fields are excluded.
  • Setup Menu [Removed] — Removed the customizable Setup menu that enabled quick navigation, as it was causing Developer Console and Agentforce UI elements to be hidden.
  • Minor Bugs Fixed — General performance and stability improvements across extension pages.
